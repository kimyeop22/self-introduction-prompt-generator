GitHub에 저장하고 링크로 공유하기

GitHub는 내 파일을 보관하는 곳입니다. ‘저장소’는 프로젝트 폴더이고, ‘Pages’는 그 안의 HTML을 웹주소로 보여 주는 기능입니다.

각자 본인의 계정으로 진행합니다.

선택 · 이 페이지에서 GitHub에 직접 등록

처음이라면 위의 ‘파일 올리기’가 간단합니다. 직접 등록은 본인 소유의 실습용 저장소 하나에만 접근 가능한 단기 인증 토큰이 있을 때 사용하세요.

  1. GitHub의 세분화 토큰 만들기를 엽니다. Resource owner에서 내 계정을 고르고 만료 기간을 짧게 설정합니다.
  2. Only select repositories에서 실습 저장소 한 개만 선택합니다. Repository permissions의 Contents를 Read and write로 설정한 뒤 발급합니다.
  3. 아래에 붙여 넣고 저장할 파일과 위치를 확인합니다. 토큰은 지금 요청을 위해 GitHub에만 보내며 초안에 저장되지 않습니다.
